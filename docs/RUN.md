# RUN-System

RUN ist die Zustandsmaschine des Projekts.

## Zustände

- **RUN 3** – Eintritt
- **RUN 14** – Kontakt
- **RUN 21** – Erwachen

## Verhalten

- RUN wird beim Boot initialisiert.
- Jeder Kammerabschluss kann RUN erhöhen.
- RUN ist nicht linear – es ist ein Tiefenmaß.

## Datenquelle

`data/run.json`
